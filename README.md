A modern, highly interactive personal portfolio website showcasing my skills, projects, certifications, and experience as a B.Tech CSE student. 

🌐 **[View Live Website Here](https://Avinesh9.github.io/Portfolio/)**

## ✨ Features

- **Dark Glassmorphic UI:** A sleek, premium aesthetic utilizing deep purple gradients, frosted glass effects, and soft neon accents.
- **Interactive Jelly Grid Background:** A custom-built HTML5 Canvas physics engine that renders a particle grid which realistically reacts to cursor movement.
- **Dynamic Resume Viewer:** A built-in retro-styled modal that seamlessly displays the resume natively within the browser without requiring external plugins.
- **Fully Responsive:** Carefully crafted media queries ensure a perfect viewing experience across desktop, tablet, and mobile devices.
- **Automated Deployment:** Configured with GitHub Actions for automated CI/CD deployment to GitHub Pages.

## 🛠️ Built With

This project was built from scratch without heavy frameworks to ensure maximum performance, customizability, and a deep understanding of core web technologies:

- **HTML5** for semantic structure
- **CSS3** for layout, animations, neumorphism, and glassmorphism styling
- **Vanilla JavaScript (ES6+)** for DOM manipulation and the custom 2D Canvas physics engine

## 📂 Project Structure

- `index.html` - The main entry point and structural layout.
- `style.css` - All styling rules, animations, and responsive media queries.
- `script.js` - Interactivity logic, modal handling, and the background canvas animation engine.

## 🚀 Getting Started Locally

To run this project on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Avinesh9/Portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` in your favorite web browser or start a local development server (like Live Server in VS Code).
